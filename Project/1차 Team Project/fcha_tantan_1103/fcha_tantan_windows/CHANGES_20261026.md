# 2026-10-26 변경 내역 (fcha_1026)

기준 코드: `fcha_1026.zip`(= FCHA_TANTAN_RENEWAL_20261021과 코드 동일). 기존 모델·필드는 지우거나 이름을 바꾸지 않았습니다.
검증: `python manage.py test` 39개 통과(기존 20 + 신규 19), `python manage.py check` 문제 없음, 360px·1440px 화면 확인.

## JSON 데이터 연동
- `fcha_tantan_json.zip` 파일을 `data/fcha_json/`에 넣음.
- `python manage.py import_fcha_json` → `priority_brands.json`(카페 841·치킨 632·편의점 37·미용실 311 = 1,821개 브랜드, 2024·2025 공시) DB 입력. 다시 실행해도 중복 없이 교체됩니다.
- 실데이터가 들어오면 예시(데모) 8개 브랜드는 목록에서 자동 제외(기존 규칙 유지, 삭제는 안 함).
- null은 0으로 바꾸지 않음. 전국 평균 매출이 범위로만 공개된 브랜드는 “하한~상한”으로 표시(1,821개 중 2025년 단일값 공개 브랜드는 일부뿐).
- 상세 창업비용은 그 해 정보공개서 “창업 부담금(가맹비·교육비·계약보증금·기타)”으로 표시. 임대보증금·권리금은 포함되지 않는다고 명시.
- 목록·지역 화면이 1,800여 개 브랜드를 매번 전부 읽지 않도록 DB 정렬 + 페이지 단위 조회로 변경.

- `import_fcha_json`의 기본 파일을 `brands.json`(있으면)으로 변경 → **브랜드 12,479개·업종 45개**, 연도 통계 22,154건, 지역 통계 367,489건(README 검증 수치와 일치). 약 22초.
- 기존 1,821개 브랜드는 같은 ID로 갱신되어 관심 브랜드 등 연결이 유지됩니다.
- `Brand.category_major`(외식·서비스·도소매) 추가. 업종 목록은 코드에 고정하지 않고 DB 브랜드에서 만듭니다(브랜드 많은 순).
- 브랜드 탐색·메인: **대분류 칩(전체/외식/서비스/도소매) + 세부 업종 선택**. 칩을 바꾸면 세부 업종은 ‘전체’로 풀리고, 세부 업종만 고르면 대분류 칩이 자동으로 켜집니다.
- 지역 살펴보기·양도양수·파트너 센터·회원가입 희망 업종도 같은 대분류별 묶음 선택으로 변경.
- 브랜드 선택 드롭다운(매장 위치·양도양수·파트너 신청·계산기)은 1만 개가 넘어 **검색 입력칸 + 자동완성**으로 변경(`/brands/lookup/?q=`).
- 공개 API `/api/v1/brands/`는 100개씩 나눠 응답(`page`, `num_pages`, `count` 추가).
- 업종 대표 이미지는 카페·치킨·미용실·편의점·제과제빵·아이스크림·음료만 있고 나머지는 매장 그림을 씁니다.
- 응답 시간(로컬): 목록·지역 0.1~0.25초.
- 테스트 43개 통과(업종 테스트 4개 추가).

- 모바일은 아이콘 한 줄 가로 스크롤, 선택한 업종이 자동으로 보이도록 이동.

## 추가: 회원가입 변경
- **주민등록번호 앞자리 입력 삭제.** 회원가입·내 정보에서 받지 않습니다(예전에 받은 생년월일 칸은 DB에 비어 있는 채로 남아 있음).
- **이메일 인증**: 이메일 입력 → [인증번호 받기] → 6자리 입력 → [인증 확인] → “✓ 이메일 인증 완료”가 떠야 가입됩니다.
  - 번호는 해시로만 저장, 10분 만료, 5회 틀리면 새로 받기, 같은 이메일 60초 재발송 제한, 한 세션 1시간 5회.
  - 인증한 이메일과 다른 이메일로 가입할 수 없고, 이미 가입된 이메일로는 번호를 보내지 않습니다.
  - 내 정보 수정에서 이미 인증한 같은 이메일이면 다시 인증하지 않습니다. 간편로그인 첫 추가 정보 입력에서도 인증합니다.
  - **메일 발송 설정**: `.env`의 `EMAIL_HOST` 등을 채우면 실제 메일이 나가고, 비워두면 서버 콘솔(검은 창)에 인증 메일 내용이 찍힙니다(개발용).
- **창업 목적 질문 먼저**: “창업을 목적으로 가입하시나요?” 예/아니오. **‘예’일 때만** 창업 방식(선택)·예산·목표 월 매출·희망 지역·희망 업종(필수)과 사업제안 수신 동의가 보입니다. ‘아니요’면 창업 조건과 사업제안 동의를 저장하지 않습니다.
- 맞춤 추천은 창업 목적 회원만, 브랜드 사업제안 대상도 창업 목적 회원만.
- 테스트 44개 통과.

## 확인이 필요한 부분 (구현했지만 외부 설정이 필요하거나 결정이 필요한 것)
- 간편로그인: 네이버/카카오/구글 개발자센터 앱 등록과 Redirect URI 등록(.env.example 참고). 실제 로그인 왕복은 키가 없어 테스트하지 못했습니다.
- 카카오 지도: `KAKAO_JS_KEY`와 플랫폼 도메인 등록 전에는 지도 대신 안내 문구가 나옵니다(주소 검색은 키 없이 동작).
- 요금제 금액(무료/29만원/별도 협의)은 화면용 **예시**이며 “예시” 표시가 붙습니다.
- 이메일 인증 실제 발송: `.env`에 메일 서버(SMTP) 정보를 넣어야 합니다. 넣기 전에는 서버 콘솔에 인증번호가 출력됩니다.
- 양도양수·후기 금액/내용은 사용자 입력값이며 플랫폼 검증값이 아니라고 화면에 명시했습니다.
