# 공공 매장 상권 연결 — 2026-11-03

Work 산출물은 `data/review/seoul_store_area_mapping_20261103`에 보존합니다.
로컬 검증·적용 스크립트는 `scripts/verify_store_area_mapping.py`입니다.
기본 실행은 검증 전용이며 `--commit`은 전체 재검증 뒤 하나의 트랜잭션으로 연결합니다.
기존 연결이 다른 경우 중단하고 전체 롤백합니다. 동일 연결의 재실행은 허용합니다.

검증 범위:

- 입력·산출물 manifest SHA-256과 JSON 건수 대조
- 원본 매장 554,092건의 ID·출처·external_id·좌표 문자열·날짜와 DB 대조
- 원본 경계 1,643건과 DB 필드·도형 대조 및 유효성 확인
- 전체 매장에 대해 Shapely STRtree의 within/touches로 공간 판정 재계산
- 내부 구멍 반영, 경계 접촉 우선 분류, 보정·버퍼·허용오차 없음
- 전체 대응표 ID 중복·누락, 상태·상권별 건수 대조
- 검토표 전체의 내부·경계 후보 및 사유 대조
- 반영 직후 DB 상권별 연결 건수 대조

유일 매칭 422,123건만 `PublicStore.area_id`에 연결합니다.
중첩 17,946건, 경계 밖 114,023건은 null로 유지합니다.
경계 접촉·좌표 오류는 각 0건입니다.
추가 DB 백업과 최초 데이터 재적재는 수행하지 않습니다.
브랜드, 원본 좌표, 경계 verified/effective_on은 변경하지 않습니다.

결과와 실제 반영 여부는 `store_area_local_verification.json`의 `committed` 및
`linked`에서 확인합니다. 검증 환경은 프로젝트 내부 `.validation_deps`에 격리했으며
Shapely 2.2.0 및 GEOS 3.14.1을 사용합니다.

두 자료의 동일 경위도 좌표계는 여전히 가정입니다. 경계의 공식 기준일·좌표계
변환 이력은 미확정이며 이번 연결도 프로젝트 미리보기입니다.
지도 Django 테스트 7개와 시스템 검사가 통과했습니다.

## 분석 화면 연결

`market/analysis.py`의 `area_store_summary`와
`brands/templates/includes/area_public_stores.html`을 통해 `/brands/bregion/`에
전체 공공 매장 수·희망 업종 매장 수·업종별 분포를 표시합니다.
전체 공공 매장의 최신 스냅샷 날짜 하나로 제한하며, 선택 상권에 유일 연결된
매장만 집계합니다. 업종별 분포는 전체 업종이며 희망 업종 수와 구분합니다.
상권 미선택·미연결 매장은 안내로, 미대응 희망 업종은 집계 불가로 표시합니다.
조건 저장 후 서버에서 다시 계산하며 지도 반경 집계와 범위를 구분합니다.
추가 데이터 적재는 하지 않았습니다. 집계·HTML 출력 테스트 2개와 기존 지도 테스트
7개, 시스템 검사가 통과했습니다.
