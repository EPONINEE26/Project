# 점주 커뮤니티 수정 안내

기존 점주 커뮤니티(`/community/`) 안의 ‘점주 이야기 / 폐점주 커뮤니티’ 탭으로 이동합니다.
폐점주 게시판은 기존 커뮤니티의 배너, 카드, 작성자 표시, 사이드바, 페이지 이동 스타일을 사용합니다.
상단과 회원 메뉴에는 기존 ‘점주 커뮤니티’ 진입점만 유지합니다.

원인: 분리한 closure_models.py, closure_admin.py, closure_views.py를 Django의 모델 로딩, 관리자 자동 등록, URL에 연결하지 않았고 DB 마이그레이션도 빠져 있었습니다. 또한 원본 커뮤니티 화면을 재사용하지 않고 독립 메뉴와 목록을 추가했습니다.
모델·관리자·URL 연결 및 마이그레이션 적용을 완료하고 기존 커뮤니티 내부 구조로 수정했습니다.
_fields.html은 폼 필드를 출력하는 공통 템플릿으로 정상입니다.

## 실행

1. ZIP을 새 폴더에 풀어주세요.
2. `.env.example`을 참고해 필요한 로컬 설정을 `.env`에 입력하세요.
3. `python -m pip install -r requirements.txt`
4. `python manage.py migrate`
5. `python manage.py runserver`
6. 점주 커뮤니티 → 폐점주 커뮤니티로 이동하세요.

전체 ZIP에는 소스, 현재 DB의 일관된 스냅샷, 데이터, 정적 파일을 포함합니다.
`.env`, 비공개 제출 증빙, 중복 backups, 가상환경, 캐시, 기존 ZIP 및 패키징 산출물은 제외합니다.
기존 회원·운영 데이터가 들어 있는 DB를 포함하므로 프로젝트 보관용 파일로 취급해주세요.

## 검증

- 폐업 커뮤니티 테스트 6개 통과: 업로드, 관리자 승인, 작성·수정·삭제, 권한, 인증 철회, 내부 탭과 원본 레이아웃.
- Django check 통과, 미생성 마이그레이션 없음.
- 추가로 실행한 brands.test_features 25개 중 22개 통과, 상권 카테고리/지역 검색/유동인구 화면 기대값 관련 3개 실패. 전체 테스트 통과 상태는 아닙니다.
