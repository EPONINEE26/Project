6. AD 1·2번은 멤버십에 포함되지 않는 별도 CPC 경매 구좌입니다. 파트너 문의에서 구좌와 희망 CPC를 입력하면 관리자가 확인할 수 있습니다. 관리자 > 광고 구좌에서 승인한 광고의 기간·브랜드·CPC·활성 여부를 설정하세요. 구좌별 활성/기간 유효 입찰 중 최고가, 동률은 등록이 빠른 순서로 노출합니다. 낙찰 단가는 본인 입찰가인 1가격 방식입니다. 기존 광고의 CPC 기본값은 0이므로 입찰가를 등록해야 노출됩니다.
   - 문의가 자동으로 승인되지는 않습니다. 기존 광고 노출 정책과 마찬가지로 관리자 검토가 필요합니다.

7. 이메일: SMTP가 없으면 서버 실행 PC의 터미널에만 번호가 출력됩니다. 이제 개발 모드임을 화면에 안내합니다. SMTP 발송 오류는 503 안내로 처리하고 실패한 인증 기록을 제거해 즉시 재시도할 수 있습니다. 발송 제한시간은 15초입니다. 번호를 브라우저에 노출하지 않습니다.

## 실행
전체 ZIP을 새 폴더에 압축 해제한 뒤 start.bat을 실행하세요. 기존 실행 스크립트가 DB 백업 후 신규 마이그레이션을 적용합니다. 수동 실행은 python manage.py migrate 이후 python manage.py runserver입니다. 원본 DB와 기존 자료는 유지했으며 신규 구조는 실행 시 적용합니다.

## 실제 이메일 발송
서버 PC의 .env에서 EMAIL_HOST, EMAIL_PORT, EMAIL_HOST_USER, EMAIL_HOST_PASSWORD, EMAIL_USE_TLS, DEFAULT_FROM_EMAIL을 메일 제공자 설정에 맞게 입력하고 서버를 재시작하세요. 다른 사람이 민기 PC의 서버에 접속하면 그 사람 PC의 CMD에는 번호가 나오지 않습니다. 실제 메일 발송은 유효한 SMTP 계정이 있어야 검증할 수 있습니다.
