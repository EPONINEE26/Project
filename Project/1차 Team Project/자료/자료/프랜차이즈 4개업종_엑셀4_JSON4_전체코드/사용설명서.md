# 서울비중 계산 결과 수정본

서울·전국 매장수가 있는데 서울비중이 비어 있던10칸의 저장 계산결과를 갱신했습니다. 값이 있는31개 행 모두 서울÷전국 비율과 일치함을 검증했습니다. 기존 수식·숫자·서식은 유지했습니다. JSON에도 seoul_share 컬럼을 추가했습니다.


이번 첨부 excel.zip의 원본4개를 사용했습니다. 03_지역집계의 이미용·커피·편의점만 조사했습니다. 기존 셀의 숫자·수식·서식·기준연도·설명문은 바꾸지 않았습니다. 다른 시트의 내용과 ZIP 부품도 바이트 그대로 보존했습니다.

## 보완 결과와 한계

|업종|2024 새 입력|2025 새 입력|남은2025 빈칸|
|---|---:|---:|---:|
|이미용|15칸|0칸(기존 입력 유지)|0칸|
|커피|0칸(기존 입력 유지)|0칸|12칸|
|편의점|12칸|3칸(GS25)|9칸|
|치킨|0칸(요청 대상 외, 원본 유지)|0칸|0칸|

실제 숫자로 보완한 값은 총30칸입니다. 공정위 표에서 해당 실적연도의 가맹점 수를 확인했습니다. 직영점은 제외했습니다. 원본에 이미 있던 값은 공시와 다르더라도 수정하지 않았습니다. 메가커피의 원본2024행 C3:E3은 공식2024표와 다르지만, 기존값 보존 요청에 따라 유지하고 `기존입력값_공시차이_보존.json`에 두 값을 기록했습니다.

**2025년 남은21칸을 실제 숫자로 채우는 작업은 완료하지 못했습니다.** 컴포즈커피·이디야커피·빽다방·투썸플레이스·CU·세븐일레븐·이마트24의 서울/경기/전국 가맹점 수입니다. 확인한 최신 공시의 가맹점 현황에2025표가 없거나 값이 비어 있습니다.2024값, 현재 매장찾기 숫자, 가맹+직영 합계, 언론의 연중 현황을2025연말 가맹점수로 대신 넣지 않았습니다. `공식표_미수록21칸.json`에서 모든 좌표·브랜드·연도·사유·공식URL을 확인할 수 있습니다. 확인일2026-10-22. 엑셀은 원래 빈 셀을 그대로 남겼고 JSON은 null과 사유를 연결했습니다. 모든 빈칸을 숫자로 채운 완성본이라고 표시하지 않습니다.

## 파일

- excel/: 원본과 같은 이름의 엑셀4개. 실제 보완은 이미용·편의점2개이고 커피·치킨은 원본과 파일해시까지 같습니다.
- json/: 엑셀4개와 일대일 대응. 모든 시트와 기존값·수식·셀좌표를 보존했습니다.
- original/: 이번 첨부의 원본4개, 비교 및 재생성용
- 보완계획.json / 지역집계_보완값과출처.csv: 추가30칸의 입력값·연도·공식 출처
- 원본보존_검증결과.json / 검증결과.txt: 보존 검증과 테스트6개 결과
- evidence/: 가맹점 수를 확인한 공식 공시표와 공시 이력 수집 자료
- code/: 빈칸 입력·원본보존·JSON저장·수집·집계·예산손익·API 코드

## JSON과 계산

`sheets`에는 모든 원본 시트를 순서대로 넣었습니다. `cells`는A1좌표 인덱스이고 value는 숫자·텍스트·수식을 원본대로 유지합니다. `changes`는 추가한 셀만 기록합니다.

`regional_aggregation`에는 year/industry/brand 복합인덱스와 seoul_franchise_stores/gyeonggi_franchise_stores/national_franchise_stores 컬럼을 제공합니다. index와data의 같은 순번이 한 행입니다. missing에는 공시표 미수록 사유와 출처가 있습니다.

엑셀의 기존 G열 서울비중 수식은 그대로입니다. 서울·전국 값이 있는 행의 비중은 저장 계산결과까지 갱신하여 파일을 열면 바로 표시됩니다. 원본에 존재하는 수식 오류나 기존 설명문의 혼합 기준도 임의로 고치지 않았습니다. 추가한30값의 기준은 CSV·JSON의 출처를 보세요.

## 재생성

압축해제 폴더에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python code/build_region_plan.py --original original --evidence evidence --output 보완계획.json
python code/preserve_workbooks.py --original original --plan 보완계획.json --output excel --json-output json
python code/fix_seoul_share.py
python -m unittest discover -s code -p "test_*.py" -v
python code/analysis.py --json json --output 분석결과.json
uvicorn api:app --app-dir code --host 127.0.0.1 --port 8000
```

build_region_plan은 같은 실적연도 표에서 빈칸에 연결할 값을 찾습니다. preserve_workbooks는 기존값 덮어쓰기를 차단하고 허용된 빈 셀만 입력합니다. 모든 다른 부품의 바이트가 같은지 확인합니다. finalize_json은 지역집계 인덱스·컬럼·사유를 제공합니다. 수집 코드는 fetch_ftc.py와scrape.py에 있습니다. 수집만으로 원본을 바꾸지 않습니다.

analysis.py는 같은 연도·지역에 한해 업종·브랜드·지역 집계, 매출비교, 업종 평균, 전년비교, 사용자입력 예산손익을 계산합니다. 원본 숫자를 그대로 사용합니다. 함수별 docstring에 pandas 함수와 계산식을 설명했습니다. API의 /summary, /sales, /validation, /budget을 제공합니다. 서버 구동은 의존성 설치 후 가능합니다. 실제 사용자 비용이 제공되지 않아 비용을 임의로 입력하지 않았습니다.

운영이익=연매출−재료비−인건비−임차료−기타운영비. monthly로 비용을 입력하면12배로 연환산합니다. 손익분기매출=고정비/(1−변동비율). 업종 평균은 선정 브랜드의 평균이며 전체 시장 공식 평균이 아닙니다.
