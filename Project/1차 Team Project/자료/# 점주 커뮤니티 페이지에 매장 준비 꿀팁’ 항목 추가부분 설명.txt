# 점주 커뮤니티 페이지에 매장 준비 꿀팁’ 분류를 마지막 항목으로 추가하고, 이 분류에 일반회원도 댓글을 작성하도록 수정한 코드 정보 
==================================================================
1. models.py
-   store_tips를 추가해 꿀팁 게시글을 구분
-  댓글의 brand에 null=True, blank=True를 설정해 인증 브랜드가 없는 일반회원도 댓글을 저장할 수 있게 완료

2. forms.py — TipsCommentForm
   fields = ('content',)로 지정해 브랜드 선택 없이 댓글 내용만 입력하도록 만든 폼

3. views.py — may_comment()
   로그인한 사용자인지 확인한 뒤, 꿀팁 글이거나 인증 점주이면 댓글을 허용합니다. 따라서 일반회원은 꿀팁에만 댓글을 작성 가능하게 만듬 

4. views.py — comment_form_for()
   꿀팁에는 새로 만든 TipsCommentForm을, 나머지 분류에는 기존 CommentForm을 사용하도록 분기

5. views.py — comment_create()
   꿀팁 이외의 글에는 점주 인증을 검사합니다. 입력이 유효하면 댓글에 작성자와 게시글을 연결하고, 인증 브랜드가 있으면 함께 연결한 뒤 기존 검수·저장 함수인 record_match()로 처리
=================================================================
