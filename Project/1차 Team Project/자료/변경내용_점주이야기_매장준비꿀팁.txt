점주 이야기·매장 준비 꿀팁 변경 설명서 (2026-11-04)

1. 제공 기능
- 게시판은 점주 이야기 하나만 제공합니다.
- 기존 분류 마지막에 매장 준비 꿀팁(store_tips)을 추가했습니다.
- 꿀팁 게시글 작성은 승인되고 계약이 유효한 점주 인증 회원만 가능합니다.
- 꿀팁 댓글은 로그인한 일반회원도 작성할 수 있습니다.
- 댓글 수정·삭제는 작성자 본인만 가능합니다. 비로그인 댓글은 허용하지 않습니다.
- 다른 분류의 댓글 권한은 기존처럼 인증 점주 전용입니다.

2. 폐점주 기능 제거 범위
- 폐점주 전용 탭, URL, 화면, 글쓰기·인증·증빙 다운로드 경로와 관리자 등록을 제거했습니다.
- 이전 /community/closure/ 및 하위 경로는 404로 처리됩니다.
- closure_views.py, closure_forms.py, closure_admin.py와 closure 템플릿들을 새 ZIP에서 제거했습니다.
- 과거 마이그레이션이 closure_files.py를 직접 참조하므로 이 파일은 삭제하지 않았습니다.
- 기존 폐점주 DB 행을 지우지 않기 위해 closure_models.py도 보관용으로 남겼습니다. 화면·URL·관리자에서는 사용하지 않습니다.
- 기존 0001/0002 마이그레이션을 지우면 설치 이력이 깨지므로 그대로 보존했습니다.
- 폐점주 데이터를 점주 게시글로 임의 변환하거나 작성자 권한을 조작하지 않았습니다.

3. 변경 파일과 이유
- community/models.py: 마지막 분류 추가. 일반회원 댓글에는 인증 브랜드가 없으므로 Comment.brand만 비워둘 수 있도록 변경.
- community/forms.py: 꿀팁용 댓글 폼을 추가하여 일반회원에게 브랜드 선택을 요구하지 않음.
- community/views.py: 꿀팁에서만 일반회원 댓글 허용. 본인 수정·삭제, 검수·신고·CSRF 보안 유지.
- community/urls.py: 폐점주 경로 제거.
- community/admin.py: 폐점주 관리자 등록 제거.
- community/templates/community/index.html: 상위 폐점주 전환 탭 제거. 마지막 분류와 댓글 정책 표시.
- community/templates/community/detail.html: 실제 댓글 권한에 따라 폼 표시.
- community/templates/community/author.html: 인증 브랜드가 없는 댓글에는 일반회원으로 표시. 게시글 브랜드를 일반회원의 브랜드로 위장하지 않음.
- community/templates/community/form.html: 댓글 수정 화면 설명 수정.
- community/closure_models.py: 기존 DB 보관용임을 명시하고 적용 이력에 없는 폐지 분류 필드는 추가하지 않음.
- community/migrations/0003_owner_tips_member_comments.py: 댓글 브랜드 선택 허용과 새 게시글 분류 반영. 데이터 삭제 작업 없음.
- scripts/package_project.py: 재압축할 때 폐지된 탭·메뉴가 다시 추가되지 않도록 구형 변환 제거.
- scripts/verify_community_package.py: 새 기능 검증 모듈 사용.
- community/tests_owner_tips.py: 새 요구사항 전용 검증 19개.
- 원본 프로젝트와 그 안의 community/tests.py는 변경하지 않았습니다. 새 ZIP에서는 폐지된 기능의 테스트를 docs/legacy_closure_tests_original.py.txt에 원문 그대로 보관하고, 새 테스트 모듈을 사용합니다.

4. 검증
- 새 기능 전용 테스트 19개 통과: 항목 순서·분류 조회·점주 글쓰기·일반회원 글쓰기 차단·일반회원 댓글·작성자 표시·본인 수정/삭제·타인 수정/삭제 차단·비로그인 차단·기존 분류 권한 유지·검수/신고/CSRF·폐점주 경로 및 관리자 제거.
- core 테스트와 합쳐 49개 중 47개 통과. 실패 2개는 매물 좌표 반올림과 지역 분석 체크박스이며, 변경 전 원본에서도 동일하게 실패함을 별도로 확인했습니다. 이번 작업에서 그 기능은 변경하지 않았습니다.
- 새 ZIP의 복사본 DB에만 마이그레이션 적용. 기존 게시글·댓글·폐점주 보관 데이터 건수 동일 확인.
- 원본 소스의 변경 대상 파일과 원본 tests.py의 해시를 비교하여 원본 미변경 확인.
- ZIP CRC 검사 및 폐점주 실행 파일 제외 여부 검사.

5. 실행
- ZIP을 기존 폴더 위에 덮어쓰지 말고 새 폴더에 압축 해제하세요. 덮어쓰면 구형 파일이 남을 수 있습니다.
- start.bat을 실행하세요.
- 수동 실행: python -m pip install -r requirements.txt / python manage.py migrate / python manage.py runserver
- 점주 이야기에서 마지막 매장 준비 꿀팁 항목을 선택하세요.
- 점주 인증 계정으로 글 작성 후 일반회원 계정으로 해당 글에 댓글을 작성할 수 있습니다.
- 테스트: python manage.py test community.tests_owner_tips --noinput


매장을 운영해 보니 물건을 갖추는 것만큼 동선을 점검하는 게 중요했습니다. 오픈 전에 주문부터 결제, 제조, 포장까지 직원들과 연습해 보세요. 자주 쓰는 도구의 위치를 조정하고, 초도 재고는 보관 공간과 추가 발주 일정을 고려해 준비하면 첫 영업의 혼란을 줄일 수 있습니다.
