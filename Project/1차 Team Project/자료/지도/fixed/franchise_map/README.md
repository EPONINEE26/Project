# 우리동네 상권지도

서울시 상권분석서비스의 지도 중심 탐색 구성을 참고한 독립적인 로컬 웹앱입니다.
API 키 입력 없이 Leaflet과 OpenStreetMap 도로 지도를 사용합니다. 인터넷 연결은 필요합니다.
서울시 서비스의 공식 데이터·기능을 복제하거나 연동한 사이트는 아닙니다.

## 실행

1. 이 폴더의 **지도실행.cmd**를 더블클릭합니다.
2. 브라우저가 열리면 이용합니다. Chrome이 아니면 실행 창의 주소(기본 http://127.0.0.1:8765/)를 Chrome 주소창에 붙여넣습니다.
3. 실행 창은 열어 두세요. 닫으면 로컬 서버가 종료됩니다.

Python 3이 필요하며 추가 패키지를 설치할 필요는 없습니다.
명령으로 실행할 때는 `python serve.py`를 사용하세요.
HTML 직접 열기는 Referer가 없는 지도 요청을 방지하기 위해 도로 타일을 불러오지 않습니다.

## 기능과 데이터 범위

- 도시 이동, 시·군·구/주소/업종/브랜드 필터
- 실제 도로 지도와 매장 위치, 상권 Polygon/MultiPolygon 겹쳐 보기
- 경계 클릭 시 경계 내부 매장만 분석 (구멍이 있는 경계 지원)
- 매장 파일에서 점포수와 브랜드 순위 계산
- 통계 파일의 연도·분기·업종·브랜드별 매출/유동인구/주거인구 표시
- 현재 지도 화면 범위 필터, 매장 결과 CSV, 분석 리포트 인쇄/PDF 저장

도시 중심은 기본 제공하지만 상세 시군구 이동·상권 경계는 업로드한 데이터가 있어야 합니다.
매장 데이터가 없는 시군구의 위치를 임의로 표시하지 않습니다.
지도의 매장 점은 성능을 위해 조회 결과 중 최대 5,000개만 그립니다. 분석과 CSV는 전체 조회 결과를 사용합니다.
현재 화면 필터는 화면 이동에 따라 바뀝니다.
매장 파일에는 시점별 영업 이력이 없으므로 연도/분기는 별도 통계에만 적용합니다.
인구·매출은 중복 집계를 막기 위해 여러 시점이나 업종을 합산하지 않고 선택 조건의 최신 분기 행을 개별 표시합니다.
통계 영역에서는 주소 검색/현재 지도 범위를 적용하지 않고 선택한 상권과 통계 조건을 적용합니다.

## 매장 JSON

배열 형식이 가장 명확합니다. 경위도는 WGS84입니다. `city`, `district`를 직접 넣을 수 있습니다.

```json
[
  {
    "brand": "본인 데이터의 브랜드",
    "name": "매장 이름",
    "category": "카페",
    "city": "서울",
    "district": "성동구",
    "rdnmAdr": "본인 데이터의 실제 주소",
    "lat": 37.5445,
    "lon": 127.0553
  }
]
```

기존 `{"브랜드명":{"regions":{"서울":[{"lat":37.5,"lon":127,"rdnmAdr":"주소"}]}}}`도 지원합니다.
`city`, `district`가 없으면 주소 또는 지역명에서 분류합니다.

## 상권 경계 GeoJSON

WGS84 `[경도, 위도]` Polygon/MultiPolygon FeatureCollection 파일을 불러오세요.
각 feature의 `properties`에 `area_code`(고유 코드), `name`(상권 이름)을 넣습니다.
`TRDAR_CD`, `TRDAR_CD_NM` 이름도 지원합니다.
투영 좌표(EPSG:5179 등)는 먼저 WGS84로 변환해야 합니다.
경계 파일을 불러오면 파란 경계가 나타나며 클릭하면 영역 내부의 매장만 조회합니다.
같은 area_code의 경계를 다시 불러오면 교체합니다.

## 통계 JSON

```json
{
  "stats": [
    {
      "area_code": "경계와 같은 코드",
      "year": 2025,
      "quarter": 4,
      "category": "카페",
      "brand": "",
      "sales": 1000000,
      "floating_population": 100,
      "residential_population": 50
    }
  ]
}
```

위 숫자는 형식 설명용이며 실제 통계가 아닙니다. 매출 단위는 원, 인구는 명으로 정규화해 넣으세요.
상권을 클릭한 후 매출·인구 탭에서 확인합니다. 통계가 없으면 미등록으로 표시합니다.
같은 area_code/year/quarter/category/brand의 통계는 다시 불러올 때 교체합니다.

## 파일과 개인정보

파일은 브라우저 메모리에서만 읽습니다. 외부 서버 업로드나 영구 저장은 없습니다.
여러 파일을 나눠 불러올 수 있으며 매장은 추가됩니다. 같은 매장 파일을 반복해서 넣으면 중복되므로 새로고침 후 한 번씩 불러오세요.
새로고침하면 입력한 데이터가 지워집니다.
예시 버튼은 가상의 매장 6개와 가상의 사각형 경계를 표시하며 실제 상권/매출을 의미하지 않습니다.
예시 상태에서 본인 파일을 불러오면 예시를 먼저 제거합니다.

## 지도 연결 오류

OpenStreetMap 표준 타일 URL을 사용하며 출처와 Referer를 유지합니다. 대량 다운로드나 차단 우회 기능은 없습니다.
Access blocked가 계속 보이면 네트워크/확장 프로그램/서비스 정책 차단 여부를 확인해야 합니다.
지도 데이터 제공자의 가용성을 보장할 수는 없습니다. 외부 지도 연결이 안 돼도 불러온 파일의 점포수 분석은 사용할 수 있습니다.
라이브러리는 jsDelivr에서 불러오며 연결 오류 시 unpkg를 사용합니다.
