상권지도 이용 방법

  1. 지도실행.cmd를 더블클릭해 로컬 주소로 접속하세요.
  2. 도시를 선택하면 실제 도로 지도로 이동합니다.
  3. 본인의 매장 JSON, 상권 GeoJSON, 통계 JSON을 불러오세요.
  4. 지역·업종·브랜드를 선택하고 지도 위 상권을 클릭하세요.

인터넷 연결은 지도 라이브러리와 도로 지도에 사용합니다. 업로드한 파일은 브라우저 메모리에서 분석하며 서버로 전송하거나 영구 저장하지 않습니다. 새로고침하면 다시 불러와야 합니다.

매출·인구는 해당 통계 파일이 있을 때만 표시합니다. 예시 데이터는 가상의 기능 시연 자료입니다. 상권 경계에는 WGS84 경위도 좌표가 필요합니다.

데이터 형식은 같은 폴더의 README.md에 정리되어 있습니다.
