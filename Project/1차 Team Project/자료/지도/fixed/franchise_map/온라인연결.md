# 나중에 온라인으로 연결하는 방법

가능합니다. 두 가지를 따로 설정할 수 있습니다.

1. **지도를 웹주소로 공개하기**: HTML/CSS/JS를 웹서버에 올립니다.
2. **온라인 데이터 서버 연결하기**: API에서 매장·상권·통계 JSON을 불러옵니다.

현재 도로 지도는 이미 인터넷의 OpenStreetMap을 사용하며 API 키 입력은 없습니다.
서울시 상권분석 사이트의 비공개 API를 가져다 쓰는 방식은 아닙니다.

## 1. 온라인 데이터 서버 연결 코드

`assets/config.js`에서 연결할 주소만 바꿉니다.

```javascript
window.MARKET_CONFIG = {
  storesUrl: 'https://본인서버주소/api/stores/',
  areasUrl: 'https://본인서버주소/api/areas/',
  statsUrl: 'https://본인서버주소/api/stats/',
};
```

위 주소는 형식 예시입니다. 실제로 데이터를 응답하는 서버를 만든 뒤 본인의 주소를 넣어야 합니다.
매장 API만 있다면 나머지 두 주소는 빈 문자열로 두면 됩니다.

같은 도메인에 API를 구축하면 아래처럼 사용할 수 있습니다.

```javascript
window.MARKET_CONFIG = {
  storesUrl: '/api/stores/',
  areasUrl: '/api/areas/',
  statsUrl: '/api/stats/',
};
```

지도 화면의 **온라인 서버 데이터 불러오기** 버튼을 누르면 연결합니다.
실제 연결 코드는 `assets/app.js`의 `loadOnline()`입니다.

```javascript
const response = await fetch(window.MARKET_CONFIG.storesUrl, {
  headers: { Accept: 'application/json' },
  credentials: 'same-origin',
  signal: AbortSignal.timeout(20000),
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const data = await response.json();
// data.stores 배열 또는 매장 배열을 지도에 표시합니다.
```

다른 도메인 API라면 해당 API 서버가 지도 사이트의 Origin을 CORS에서 허용해야 합니다.
HTTPS 사이트에서는 HTTPS API를 사용하세요. 브라우저 코드에는 서버 비밀키를 넣지 않습니다.
인증이 필요한 API와 데이터 저장용 DB는 별도로 구축해야 합니다.
이 설정 파일만으로 서버나 DB가 자동 생성되지는 않습니다.

## 2. 서버의 응답 형식

### GET /api/stores/

```json
{"stores":[{"brand":"브랜드명","category":"카페","city":"서울","district":"성동구","rdnmAdr":"실제 주소","lat":37.5445,"lon":127.0553}]}
```

### GET /api/areas/

```json
{"type":"FeatureCollection","features":[]}
```

features에 실제 Polygon 또는 MultiPolygon 상권 경계와 `area_code`, `name` 속성을 넣습니다.

### GET /api/stats/

```json
{"stats":[{"area_code":"실제 상권 코드","year":2025,"quarter":4,"category":"카페","brand":"","sales":1000000,"floating_population":100,"residential_population":50}]}
```

숫자는 형식 예시이며 실제 통계가 아닙니다. 단위는 원/명입니다.
현재 클라이언트는 전체 데이터를 읽고 브라우저에서 필터링합니다.
페이지네이션이 있는 API는 이 화면에 필요한 전체 데이터 스냅샷을 제공하는 엔드포인트를 연결하거나 페이지 순회 코드를 추가해야 합니다.
대규모 운영에서는 현재 화면 범위에 따른 서버 조회와 서버 집계 API로 확장하는 것이 필요합니다.

## 3. 사이트를 온라인에 올리는 코드

HTML/CSS/JS 정적 호스팅을 사용하면 빌드 과정 없이 다음 파일을 배포하면 됩니다.

```text
index.html
assets/config.js
assets/core.js
assets/app.js
assets/app.css
```

또는 함께 제공한 Dockerfile로 컨테이너 서버에서 실행할 수 있습니다.

```bash
docker build -t market-map .
docker run --rm -p 8080:8080 market-map
```

이후 http://localhost:8080/ 에서 확인합니다.
온라인 컨테이너 호스팅에서는 외부 HTTPS 주소를 서비스에 연결하면 됩니다.
호스팅이 PORT 환경변수를 지정하면 서버는 그 포트를 사용합니다.
Docker 이미지는 Python 정적 파일 서버를 포함한 소규모 사용용 예시입니다.
트래픽이 큰 공개 서비스에는 정적 호스팅/CDN과 별도 API 서버를 사용하세요.

아직 실제 서버 주소로 배포하거나 외부 계정·유료 서비스에 연결하지 않았습니다.
배포 후에도 업로드 파일은 사용자 브라우저 메모리에만 있고 DB에 영구 저장되지 않습니다.
