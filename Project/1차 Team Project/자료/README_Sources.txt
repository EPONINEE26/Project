미용실 브랜드 2024-2025 자료 (출처 명시 버전)

포함 브랜드별 엑셀 5개:
- 블루클럽_2024-2025_서울경기_출처명시.xlsx
- 박승철헤어스투디오_2024-2025_서울경기_출처명시.xlsx
- 제오헤어_2024-2025_서울경기_출처명시.xlsx
- 이철헤어커커_2024-2025_서울경기_출처명시.xlsx
- 에이바헤어_2024-2025_서울경기_출처명시.xlsx

출처 방식
1. 프차몰(FCHAMALL): 사용자가 지정한 브랜드별 프차몰 주소를 주요 출처로 기록했습니다.
2. 점포가이드(JUMPO.SHOP): 연도별 개점·계약 종료·해지·지역별 점포 수를 제공하는 공정위 정보공개서 기반 요약 페이지를 보조 출처로 기록했습니다.
3. 공정거래위원회 가맹사업거래 정보공개서 포털: 원자료 기관/검색 포털로 구분해 기록했습니다. 일반 포털 링크는 개별 브랜드 원문 문서에 직접 연결되는 주소가 아니므로 그렇게 설명했습니다.

Excel sheets
- 연도별 요약: 연도별 총점포/가맹/직영, 신규 개점, 계약 종료, 계약 해지, 종료+해지 합계, 가맹점 평균 월매출, 출처 URL, 공란 사유
- 서울경기 점포수: 2024/2025년 서울/경기 점포 수. 값이 공개 표에서 확인되지 않으면 빈칸과 사유를 표시했습니다.
- 출처와 기준: 사이트명, 페이지 기준일, 목적, 정확한 URL, 용어 설명과 한계.

중요한 정의
- 신규 개점 수는 해당 연도 신규 개점 수이며, 누적 창업점 수가 아닙니다.
- 계약 종료 + 계약 해지 합계는 정보공개서의 계약 관련 지표이고, 실제 물리적 폐점과 항상 같지는 않습니다.
- 가맹점 평균 월매출은 기존 가맹점 평균이며 신규 창업 매장의 첫 달 매출/수익이 아닙니다. 첫 달 매출은 공개자료를 찾지 못해 공란입니다.
- 빈칸은 0을 뜻하지 않습니다.
- 박승철헤어스투디오와 이철헤어커커의 2025년 수치는 조사 시 확인한 브랜드별 공개 요약 페이지가 2024년 실적까지만 제공해 공란입니다.
- 제오헤어의 2024년 서울/경기 지역별 점포 수는 확인 가능한 공개 표에서 찾지 못해 공란입니다.

Code files
01_웹스크래핑_원문수집.py: Selenium으로 10개 출처 페이지(브랜드 5개 × 출처 2개)를 열고 자동 스크롤하며 HTML과 본문 텍스트를 저장합니다.
02_엑셀저장_브랜드별.py: 동봉된 미용실_브랜드별_2024-2025_출처자료.json으로 5개 엑셀을 생성합니다.
03_전체실행_스크래핑과엑셀저장.py: 01과 02를 순서대로 실행합니다.

설치
pip install -r requirements_웹스크래핑_엑셀.txt

실행
python 01_웹스크래핑_원문수집.py
python 02_엑셀저장_브랜드별.py

엑셀 내 출처 URL은 각 행에 넣었습니다. 2024/2025의 연도 매핑은 공개 페이지에 나타난 연도별 실적표를 기준으로 정리했습니다. 최신 공시가 없는 브랜드의 2025년 수치는 추정하지 않았습니다.
