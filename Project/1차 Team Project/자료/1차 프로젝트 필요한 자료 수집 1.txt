
공정거래위원회 가맹사업거래 '정보공개서 표준 XML/CSV' (가장 정확한 브랜드 데이터)

• 어디서 받나: 공정위 가맹사업거래 공식 홈페이지의 데이터 개방 코너 또는 공공데이터포털(data.go.kr)에서 "공정거래위원회_가맹본부 정보공개서" API 및 적격 데이터를 신청합니다.
• 얻을 수 있는 것: 브랜드별 매년 전국 가맹점 신규개점 수, 계약종료(폐점) 수, 계약해지 수, 명의변경 수의 원천 수치(전년도 기준 결산 데이터)를 확보할 수 있습니다.
• 한계점: 공정위 정보공개서 자체에는 '서울시 강남구에서 몇 개 열었다' 같은 '시·군·구 단위'의 연도별 개·폐점 수가 상세히 쪼개져 있지 않고 시·도(서울시 전체) 단위까지만 나오는 경우가 많습니다. 이를 해결하기 위해 아래 2번과 3번 데이터를 결합해야 합니다.

2. 서울시 열린데이터광장 '서울시 상권분석서비스(점포)' (지자체 상권 데이터)

• 어디서 받나: 서울시 열린데이터광장(data.seoul.go.kr)에서 "서울시 상권분석서비스(점포)" 또는 "서울시 일반음식점/휴게음식점 인허가 정보" 데이터를 다운로드합니다.
• 얻을 수 있는 것: 서울시 내 모든 행정동/자치구별 커피전문점(업종코드)의 분기별 총 점포 수, 개업 점포 수, 폐업 점포 수, 개업률, 폐업률이 로우 데이터(Row Data)로 완벽하게 제공됩니다.
• 한계점: 이 데이터는 '커피 업종 전체'의 통계이기 때문에, 이 안에 메가커피가 몇 개인지, 컴포즈커피가 몇 개인지는 브랜드명이 필터링되어 있지 않습니다.

3. 행정안전부 '지방행정인허가데이터포털 (LOCALDATA)' (브랜드별 구별 위치 추적의 핵심)

• 어디서 받나: 지방행정인허가데이터포털(localdata.go.kr)에서 "휴게음식점" 업종의 전체 데이터를 받습니다. (전국 또는 서울시 파일)
• 얻을 수 있는 것: 서울시에서 허가받은 모든 커피숍의 '인허가 일자(개점일)', '폐업 일자(폐점일)', '상호명', '소재지 도로명 주소(OO구 OO동)' 가 실시간/매월 단위로 업데이트되어 포함되어 있습니다.
• 수집 가치: 이 데이터야말로 원하시는 분석의 핵심 마스터 키입니다. 상호명 텍스트에 "메가MGC커피", "컴포즈커피", "투썸플레이스" 등을 검색(텍스트 파싱)하여 필터링하면, 해당 브랜드가 '강남구'에서 '2024년 3월 15일에 개업'했고 '2025년 10월 10일에 폐업'했는지를 완벽하게 역추적할 수 있습니다.

📊 데이터 융합 및 가공 프로세스 시뮬레이션

이 데이터를 가져와서 원하시는 알고리즘이나 DB를 구축할 때, 데이터는 아래와 같은 구조로 흐르게 됩니다. 예를 들어 '강남구 내 메가커피의 연도별 개·폐점 추이'를 뽑아내는 가상의 파이썬 데이터 처리 예시를 시각화해 드립니다.

💡 크롤링 및 고급 데이터 연동을 위한 개발 팁

1. 상호명 정제(Text 정규화): LOCALDATA에서 상호명을 추출할 때, 점주들이 가맹점을 등록할 때 메가MGC커피 강남역점, 메가커피(강남점), MEGA COFFEE 등 제각각으로 입력합니다. 따라서 정규표현식(Regex)을 이용해 ^메가.*커피 또는 브랜드 핵심 키워드를 포함하는 텍스트 마스킹 작업을 거쳐야 데이터 누락이 없습니다.
2. 공정위 정보공개서 번호(가맹본부 ID) 매핑: 수집한 브랜드별 구별 개폐점 데이터의 총합이, 공정위 정보공개서에 등록된 서울시 전체 개폐점 수 총합과 일치하는지 교차 검증(Cross-validation)하는 파이프라인을 구축하면 데이터의 신뢰도가 민간 플랫폼(마이프차 등) 수준으로 올라갑니다.
사이트 제작을 위해 직접 DB(MySQL, PostgreSQL 등)를 구축하여 이 로우 데이터들을 정기적으로 적재(ETL)하는 시스템을 기획 중이신가요? 구체적인 데이터 인프라나 개발 스택을 말씀해 주시면 API 연동 규격이나 DB 테이블 설계 방향도 조언해 드릴 수 있습니다.
