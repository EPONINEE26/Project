# 추가 수정: 전체 브랜드 검색 · 다중 비교 · 공통 UI

## 회수 계산기

이전 목록이 일부만 보인 원인은 `Brand.name` 컬럼 가공이 아니라 이름순 정렬 뒤 `[:30]`으로 제한한 목록과 검색 응답이었습니다.

- 기준 브랜드 드롭다운은 실제 브랜드 **12,479개 전체**를 **45개 업종**으로 묶어 표시합니다. 브랜드 이름은 괄호·영문 등을 삭제하지 않고 DB 원문을 사용합니다.
- 첫 진입은 선택하지 않은 상태입니다. 이전처럼 임의 브랜드를 넣지 않습니다.
- 검색어를 입력하면 이름 일부가 포함된 브랜드를 즉시 찾습니다. 영문 대소문자는 구분하지 않습니다.
- 현재 데이터에서 `메가`는 `메가엠지씨커피(MEGA MGC COFFEE)`, `오메가참치` 등을 포함해 12개와 일치합니다. 이름 앞부분에 입력어가 있는 후보를 먼저 제안합니다.
- 화면에 제안하는 후보는 최대 8개이고, **일치하는 전체 결과는 아래 드롭다운에 모두 유지**합니다. 검색어를 지우면 전체 목록으로 돌아갑니다.
- 후보 클릭 또는 드롭다운 선택 후 **참고값 불러오기**를 누르면 해당 브랜드의 매출·초기 비용을 가져옵니다.
- 기본 데이터는 서버에서 전체 제공하고 브라우저에서 `includes`로 부분검색합니다. 기존 공용 검색 API도 Django `name__icontains` 검색을 사용합니다. 계산기의 전체 목록은 공용 API의 30개 응답 제한과 분리했습니다.

## 비교함·브랜드 비교

- 최대 2개에서 **최대 10개**로 확대했습니다. 홈 카드, 지역 표, 상세 페이지, 비교함, 비교표, 그래프, CSV에 동일하게 적용했습니다.
- 상단 선택 브랜드 표시에서 개별 해제 또는 전체 비우기를 할 수 있습니다.
- 비교표는 항목명을 왼쪽에 고정하고 브랜드별 열 너비를 유지합니다. 화살표 버튼·스크롤·터치로 옆 브랜드를 확인합니다. 표 머리글은 표 내부의 세로 스크롤에서도 유지됩니다.
- 그래프에는 선택한 모든 브랜드를 서로 다른 색으로 표시합니다. 그래프 항목은 기존처럼 최대 2개를 선택하며, 항목별 단위·눈금을 구분합니다.
- 모바일에서는 선택 브랜드 목록을 옆으로 넘기고, 그래프는 표 위에 배치합니다. 하단 비교함도 한 줄로 넘길 수 있도록 구성했습니다.
- 기본 FAQ의 이전 2개 안내는 migration으로 변경합니다. 관리자가 따로 작성한 답변은 덮어쓰지 않습니다.

## 햄버거 메뉴

로그인 여부와 관계없이 메뉴 마지막 두 항목은 **점주 커뮤니티 → 고객센터** 순서입니다. 메뉴가 길어지면 화면 안에서 스크롤할 수 있습니다.

## 전체 사이트 디자인과 움직임

도우미에만 한정하지 않고 공통 CSS와 JavaScript를 통해 주요 공개 화면 전체에 적용했습니다.

- 공통 버튼: 블루 그라데이션, 빛이 스치는 호버 효과, 누르는 위치에서 퍼지는 짧은 클릭 효과
- 메인 배너: 문구 순차 등장, 은은한 빛 레이어, 마우스 위치에 반응하는 작은 빛 이동
- 페이지 제목·브랜드 카드·커뮤니티 글·매물 카드: 짧은 등장 효과와 부드러운 호버 반응
- 공통 메뉴·패널·입력창: 밝은 배경 그라데이션, 얇은 테두리와 그림자, 초점 표시
- 지역 요약·계산기 결과·커뮤니티 배너·고객센터: 같은 블루 계열의 빛 효과
- 탄탄 도우미: 말풍선 아이콘, 그라데이션 버튼, 빛 반사, 부드러운 패널 열기. 모바일은 작은 아이콘 버튼

강제 스크롤이나 자동 페이지 이동은 없으며, OS의 모션 감소 설정에서는 모션을 끕니다. 외부 애니메이션 라이브러리나 유료 서비스는 필요 없습니다. 참고 사이트의 실제 움직임은 이번 환경의 접속 지연으로 직접 검증하지 못했으며, 요청한 절제된 강도를 기준으로 구현했습니다.

## 적용·검증

ZIP 전체를 새 폴더에 압축 해제한 뒤 `start.bat`을 실행하세요. 기존 PC에서 데이터를 추가했다면 현재 `db.sqlite3`, `.env`, `private_media`를 새 코드 폴더에 가져온 후 실행하세요. 상세 절차는 `UPDATE_GUIDE_20261030.md`에 있습니다. 이전 CSS가 남으면 브라우저에서 `Ctrl+F5`로 새로고침하세요.

전체 Django 테스트 **75개 통과**, 시스템 검사·migration 검사·7개 JavaScript 문법 검사 통과. 브라우저에서는 Django 렌더링 결과를 사용해 전체 옵션 수, 부분검색·선택·목록 복원, 다중 비교 스크롤, 메뉴 순서, 도우미 열기 및 데스크톱/390px 레이아웃을 확인했습니다. 실제 Windows 실행 및 실제 Django 서버에 연결한 브라우저 저장 흐름은 이 환경에서 검증하지 않았습니다.
