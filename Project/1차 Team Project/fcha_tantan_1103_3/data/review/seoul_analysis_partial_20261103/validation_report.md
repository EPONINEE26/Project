# 지역상권분석 부분 가공 검증 보고서

## 결과와 사용 범위

루트 01_sources.json은 수집일 2026-11-03을 반영한 DataSource 2건입니다. 두 note에 "프로젝트 자료 취합일을 수집일로 사용"을 기록했습니다. url은 첨부의 직접 원문 경로가 확인되지 않아 빈 문자열입니다.
루트 02_areas.json, 04_population.json은 빈 배열입니다. 필수 메타데이터 부족으로 정상 적재 대상으로 승인한 경계·인구는 0건입니다.
review_only_DO_NOT_IMPORT에는 실제 숫자 좌표와 인구 수치가 들어 있는 검토용 JSON이 있습니다. 형식은 model/fields이며 모델의 허용 필드만 사용합니다. 단, 미확인 필수 필드(version/effective_on/unit)는 생략했습니다. 이 파일은 현재 full_clean을 통과하지 못하며 적재하지 마세요. 임의 날짜·버전·단위를 넣거나 비어 있는 비 nullable 필드에 null을 넣지 않았습니다.

## 좌표계와 출처 확인 근거

- 공식 경계 자료: https://data.seoul.go.kr/dataList/OA-15560/S/1/datasetView.do (2026-11-03 확인). 공식 안내에는 EPSG:5181이 명시되어 있습니다. 그러나 첨부 geometry는 126~127, 37~38 부근 숫자이고 중심점 X/Y는 별도 투영좌표 형태입니다. 첨부가 어떤 변환을 거쳤는지 입증하는 기록은 없습니다. 공식 원자료 CRS가 첨부 geometry CRS라는 결론을 내리지 않았습니다. EPSG:5181로 간주한 재투영도 하지 않았습니다.
- geometry는 원본의 숫자·순서를 유지했습니다. WGS84 확인 완료로 표시하지 않습니다. 관측 범위는 경도 126.79714358864027~127.17513180089203, 위도 37.43369845340053~37.69403117483303입니다.
- 공식 경계 페이지의 ZIP 수정일 2023-10-23 및 페이지 갱신일 2026-09-11은 첨부 경계의 기준일·버전 근거가 아닙니다.
- 공식 인구 자료: https://data.seoul.go.kr/dataList/OA-15568/S/1/datasetView.do . 상권 영역 내 생활인구라는 설명과 제공 기준 변경 안내를 확인했습니다. 첨부 표의 단위 및 일평균/분기누계 정의는 확인되지 않았습니다. 공식 페이지 날짜를 통계 기준 분기 또는 경계 기준일로 대체하지 않았습니다.
- 두 링크는 관련 공식 자료의 근거입니다. 첨부 파일의 직접 원문임은 확인되지 않아 DataSource.url에는 넣지 않았습니다.

## 개별 경계 검증과 제외

Shapely 2.2.0을 임시 분석 환경에서 사용해 Polygon/MultiPolygon, 비어 있지 않은 도형, 링 최소 4점·닫힘, 2차원 숫자 좌표·유한성·경위도 범위, 폴리곤 위상 유효성을 검사했습니다. 서울 주변 사각 범위(126.7~127.3, 37.4~37.75)도 검사했습니다. 공식 서울 경계와의 엄밀한 포함 검사는 수행하지 않았으며 주변 범위 검사를 서울 소속 검증 완료로 표현하지 않습니다. CRS가 미확인이므로 모든 verified는 false입니다. 좌표 보정이나 make_valid는 하지 않았습니다.

## 인구 매칭과 수치 검사

원본 상권 코드가 없으므로 상권_코드_명+자치구+행정동을 TRDAR_CD_N+SIGNGU_CD_+ADSTRD_CD_와 비교했습니다. 모든 공백만 제거하고 문장부호, 물음표, 축약 행정동은 치환하지 않았습니다. 상권 유형도 일치하는지 확인했습니다. 유사도 매칭은 사용하지 않았습니다.

유일 대응 및 경계·분기·정수 검사 통과 후보 4,070건, 미매칭 32,211건, 다중 매칭 0건입니다. 후보 area_id+period+floating 중복은 0건입니다. 원본 전체의 정규화 이름+자치구+행정동+분기 중복도 0건입니다. 전체 인구는 소수·음수·NaN·Infinity 없이 정수로 전환할 수 있었습니다. 오류나 누락 값을 0으로 채우지 않았습니다. 합계 차이는 제외 사유로 쓰지 않았고 원본 값도 보정하지 않았습니다. 미매칭·제외 32,218행(인구 32,211+경계 7)은 rejected_rows.csv에 원본 전체 행과 사유를 보존했습니다.

전체 원본의 분포 합계 불일치: 연령 25,187행, 시간 25,080행, 요일 25,835행. distribution_mismatches.csv에는 전체 원본의 행별 차이와 후보 여부를 기록했습니다. 원인은 추정하지 않았습니다.

## ID와 파일 검증

DataSource는 경계=1, 인구=2로 고정했습니다. 검토용 CommercialArea는 검사 통과 code 문자열 오름차순으로 1부터, PopulationStat는 (code, YYYYQn, 원본 행 번호) 오름차순으로 1부터 부여했습니다. 같은 원본과 검사 기준을 재실행하면 동일 ID입니다. 메타데이터나 통과 집합이 변경되면 ID는 재확정해야 합니다. 비어 있는 분석 테이블 최초 적재 기준이며 기존 DB의 동일 PK를 덮어쓰는 용도가 아닙니다.

UTF-8 JSON 최상위 배열, model/fields만 사용, 허용 필드명(schema.json 대조), ID 정수, source_id·검토용 area_id 참조 및 후보 고유키를 검사했습니다. 좌표 439,892개 값이 JSON 숫자임을 확인했습니다. DataSource의 수집일은 ISO YYYY-MM-DD입니다. 검토용 필수 필드 부족은 실패로 명시하며 정상 적재 검증 통과로 취급하지 않습니다. 원본 Excel SHA-256이 이전 조사와 동일함을 확인했습니다.

Django 전체 프로젝트와 DB를 실행하지 않았습니다. 실제 management command 실행 검증 완료는 아닙니다. 로컬 import_analysis.py의 Decimal→문자열 변환은 이번 파일 가공의 중단 사유로 삼지 않았습니다. 기존 코드는 변경하지 않았으며 숫자 좌표 파일도 로컬에서 적재하면 문자열로 변환될 수 있습니다.

## 남아 있는 정확한 확인 사항

1. CommercialArea.version: 첨부와 일치하는 경계 버전 식별자·근거가 없습니다.
2. CommercialArea.effective_on: 첨부 경계가 적용된 기준 날짜가 없습니다. collected_on으로 대체하지 않습니다.
3. boundary의 CRS: 공식 원자료는 EPSG:5181이지만 첨부 숫자의 변환 이력·CRS 명시가 없습니다. 원본 생성/변환 코드 또는 내보내기 설정이 필요합니다.
4. PopulationStat.unit: 첨부 수치의 단위와 평균/누계 정의가 없습니다. 원문 필드 설명이 필요합니다.

현재 사용할 수 있는 정상 적재 파일은 01_sources.json입니다. 경계·인구를 정상 적재하려면 위 근거가 필요합니다. 모델 완화를 임의로 수행하지 않았습니다.
