# 서울 공공 상가 적재·지도 연결

## 화면 통합 변경

지도 클릭·매장 핀 클릭·희망 위치 핀 드래그가 희망 주소와 숨김 좌표를 갱신합니다. 주소검색으로도 동일 핀과 반경 원이 이동하며 반경 선택 변경 시 즉시 재조회합니다. 변경한 조건의 영구 저장 및 인구 카드 갱신은 기존 조건 저장 버튼을 사용합니다. 저장 매장·인증 점주 매장은 서버에서 구면 거리 기준으로 반경을 검사하고 표시 제한을 적용하며 카카오 결과도 반경 밖 마커를 제외합니다. 공식 상권 경계는 위치를 바꾸면 기존 표시를 지우고 조건 저장 후 다시 연결합니다.

반경 원의 사각 경계 안이지만 원 밖인 매장의 제외·건수 및 잘못된 반경 검증을 포함한 지도 관련 Django 테스트 6개 통과. 숨김 Chrome SDK 모형에서 지도 클릭 → 주소 반영 → 반경 변경 → 주소검색으로 핀 재이동을 확인했습니다.

사용자 요청으로 별도의 '공공 상가 · 서울' 탭과 추가 업종 선택 줄을 제거했습니다. 지도 탭은 인증 점주 등록 매장과 전국 장소검색 두 개입니다. 기본 전국 장소검색에서 지도 범위의 저장된 상가정보를 먼저 표시하고, 결과가 없거나 로컬 조회가 실패하면 같은 범위의 카카오 검색을 이용합니다. 카카오 검색에는 검색어가 필요합니다. 아래 최초 연결 기록의 3개 모드 설명은 변경 전 기록입니다.

통합 후 숨김 Chrome의 SDK 모형 테스트에서 탭 2개, 저장 매장 표시, 검색어 전달, 인증 모드, 카카오 자동 검색, 저장 매장 복귀를 확인했습니다. Django 시스템 검사도 통과했습니다.

## 저장 결과

- 원본: fdata/seoul_store.csv. Work 산출물 manifest의 원본 SHA-256과 일치합니다.
- 입력 묶음: data/review/seoul_public_stores_20261103.
- 출처 ID 3, 업종 247개, 공공 매장 554,092개를 저장했습니다.
- manifest process_order의 58개 JSON 해시와 건수를 확인했습니다. 업종·매장 테이블이 비어 있고 출처 ID 3이 미사용임을 확인한 뒤 최초 적재했습니다.
- 56개 매장 JSON을 한 트랜잭션에서 필드·좌표·관계 ID·고유 식별자 검증 후 bulk_create로 저장했습니다. 오류 발생 시 전체를 롤백합니다. 기존 ID 덮어쓰기는 허용하지 않습니다.
- 원본 raw·정밀 좌표 문자열·5자리 우편번호를 보존했습니다. brand_id와 area_id는 null입니다.
- 묶음에 포함된 점(.)으로 시작하는 임시 파일 4개는 적재 대상에서 제외했습니다. 원본 보관본을 삭제하거나 수정하지 않았습니다.
- 대용량 매장 JSON은 review에 그대로 보관합니다. data/analysis/07_public_stores.json은 이번 적재에 사용하지 않았습니다.

## 지도 동작

- 지역상권분석 기본 모드: 공공 상가 · 서울.
- 지도 이동 또는 범위 검색 시 현재 범위의 공공 매장을 조회합니다. 검색어는 매장명 또는 공공 업종명에 적용하며 공공 업종 선택도 제공합니다.
- 매장 API: /market/map/public-stores/?west=126.97&south=37.49&east=127.00&north=37.51.
- 로그인과 GET이 필요하며 범위·업종 ID·날짜를 검증합니다. 범위가 1도보다 넓으면 확대를 요청합니다.
- 최신 프로젝트 스냅샷을 조회하고 조건 일치 전체 건수와 최대 500개 위치를 구분합니다. 공시 브랜드 카테고리와는 별개인 공공 업종 분류를 사용합니다.
- 지도 원본 좌표는 문자열로 보존하고 숫자 변환식 인덱스로 범위를 조회합니다. 날짜+위도+경도의 복합 인덱스로 기존 약 1.65초의 예시 조회가 약 0.07초로 감소했습니다(로컬 측정, 환경에 따라 다름).
- 프로젝트 스냅샷 2026-11-03은 공식 영업 기준일이 아닙니다. 현재 영업 여부·프랜차이즈 여부를 단정하지 않습니다.
- 인증 점주 모드와 카카오 장소검색도 유지합니다. 기존 마이그레이션/DB에 존재하지만 모델에서 누락된 StoreLocation.is_public을 복원했습니다. 공개 동의와 인증 확인 조건을 유지하며 새 삭제 마이그레이션은 만들지 않았습니다.

## 검증

- 관련 Django 테스트 9개 통과: 범위·스냅샷·검색·업종 필터, 500개 제한, 잘못된 입력, 인증/GET 제한, 점주 공개 동의, 적재 검증 전용 실행, 실제 저장, ID 충돌, 후반 파일 오류의 전체 롤백, 해시 변조 거부, 정밀 좌표 보존.
- 실제 DB에서 예시 범위 3,202건 중 500개 반환, 업종 247개 반환, 기존 등록 매장 API 정상 응답 확인.
- 실제 DB의 지역상권분석 페이지 및 경계 API HTTP 200 확인. 기존 사용자 저장 조건은 검증 후 롤백했습니다.
- 숨김 Chrome에서 실제 maps.js를 실행해 기본 공공 모드, 업종 선택, 검색어 전달, 인증 모드, 카카오 모드, 공공 모드 복귀를 확인했습니다. 이 테스트의 카카오 SDK와 API 응답은 모형이며 실제 외부 SDK 지도 렌더링 검증과는 다릅니다.
- 마이그레이션 0010·0011 적용. Django 시스템 검사 및 makemigrations --check 통과.
- 앞선 전체 분석 테스트의 기존 폼 필수값 기대 불일치 2건은 별도이며 이번에 폼 설정을 변경하지 않았습니다.
