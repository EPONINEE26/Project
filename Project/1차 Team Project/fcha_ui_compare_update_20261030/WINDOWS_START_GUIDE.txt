프차 탄탄 Windows 실행 수정본 (2026-10-30)

1. ZIP을 먼저 다운로드한 뒤, 압축 폴더 안에서 실행하지 말고 전체 압축을 풉니다.
   권장 위치: C:\workspace\fcha_tantan_windows
   기존 작업 폴더는 그대로 두고 새 폴더에 풉니다.
2. manage.py와 같은 폴더의 start.bat을 더블클릭합니다.
   관리자 권한으로 실행할 필요는 없습니다.
3. 첫 실행에는 인터넷이 필요합니다. Python을 찾고 필요한 패키지를 설치합니다.
   설치 중 검은 창을 닫지 마세요. 환경에 따라 몇 분 걸릴 수 있습니다.
4. 서버가 준비되면 홈페이지가 기본 브라우저에 열립니다.
   기본 주소는 http://127.0.0.1:8000/ 입니다.
   8000번이 사용 중이면 8001~8020 중 빈 포트를 사용합니다.
   실제 주소는 실행 창의 Server is ready 줄을 확인하세요.
5. 검은 창을 열어 둔 채 이용합니다. 종료는 Ctrl+C입니다.
   Python 코드 수정 후에는 서버를 종료하고 start.bat을 다시 실행하세요.

작동하지 않을 때
- 오류 창은 자동으로 닫히지 않습니다.
- logs\startup.log 파일 또는 오류 화면을 대화에 첨부해 주세요.
- Python을 찾지 못했다면 C:\python313\python.exe가 있는지 확인해 주세요.
- 지원 범위: Python 3.10~3.14. 알려주신 Python 3.13 경로도 자동 확인합니다.
- 인터넷/인증서/회사 보안 정책 때문에 설치가 막히면 로그를 통해 구분합니다.
- 브라우저만 안 열리면 실행 창에 표시된 http 주소를 직접 입력하세요.

변경 내용
- python 명령 하나에 의존하지 않고 py 런처, C:\python313, 사용자 설치 경로,
  레지스트리, PATH에서 사용할 수 있는 Python을 찾습니다.
- 복사된 가상환경은 배포본에서 제외하고 해당 PC에서 새로 만듭니다.
- 기존 .venv가 작동하지 않으면 .venv_backup_시간 폴더로 보존하고 재생성합니다.
- Django뿐 아니라 pandas, openpyxl, 소셜 로그인 관련 모듈과 설치 상태를 검사합니다.
- DB 백업/마이그레이션과 관리자 계정 준비 절차를 유지합니다.
- 포트 사용 중인 다른 프로그램을 강제로 종료하지 않습니다.
- 오류 로그와 직전 실행 로그(startup.log.previous)를 보존합니다.
- start.bat은 이 실행에만 PowerShell 실행 정책을 지정합니다.
  Windows 전체 실행 정책, 방화벽, 보안 설정은 수정하지 않습니다.

기존 작업 자료가 있을 때
- 기존 db.sqlite3에 신규 회원/데이터를 추가했다면 첨부 DB로 덮어쓰지 마세요.
- 이번 기능 확장은 전체 새 코드를 사용해야 합니다.
  새 폴더에 기존 PC의 db.sqlite3, .env, private_media를 가져온 뒤 실행하세요.
  UPDATE_GUIDE_20261030.md에 자세한 적용 방법이 있습니다.
- 계정과 API 키는 기존 .env를 유지하세요.

검증 범위
- 별도의 Linux Python 환경에서 패키지 설치, DB 준비, Django 검사,
  기존 테스트 및 HTTP 접속을 확인합니다.
- 민기님 Windows PC에서 BAT/PowerShell을 직접 실행한 결과는 아닙니다.
