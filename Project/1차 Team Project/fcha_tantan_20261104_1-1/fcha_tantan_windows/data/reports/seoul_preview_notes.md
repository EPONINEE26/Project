# 서울 상권 세미 프로젝트 미리보기

- 자료 취합일: 2026-11-03. 공식 경계 기준일은 미확인으로 null을 저장합니다.
- 로컬 버전: project-preview-20261103. 공식 경계 버전을 의미하지 않습니다.
- 경계 1,643건: 검토 보고서의 도형 검사 통과 자료만 사용합니다. 원본 파일 SHA-256을 확인하며 잘린 경계 1건과 자기교차 6건은 계속 제외합니다.
- 경위도 형태의 원본 좌표를 변환 없이 사용합니다. CRS·변환 이력의 공식 검증을 의미하지 않으며 verified=false를 유지합니다.
- 인구 매칭: 공백 제거 후 상권명+상권유형이 경계 집합에서 유일하게 일치하는 경우에만 연결합니다. 유사도 매칭은 하지 않습니다.
- 원본의 행정동 값은 상권명 축약 등으로 경계 행정동과 다른 경우가 있어 매칭 조건에서 제외했습니다. 일부 자치구도 다릅니다. 이름과 유형 일치는 동일 상권을 보장하는 공식 코드 연결이 아니므로 미리보기로 한정합니다.
- 연결 결과: 인구 36,093건, 1,642개 상권. 미연결 188건은 대응표에서 확인할 수 있습니다. 인구 22개 분기를 보존합니다.
- 인구 단위는 '원자료 수치'입니다. 명·일평균·분기 누계로 단정하지 않으며 원본 수치를 합산·보정하지 않습니다.
- 원본 대응표: seoul_population_mapping.csv. 검토 원본과 보고서는 data/review에 보존합니다.
- 공식 검증 경계가 겹치면 우선 사용하며 여러 상권이 중첩되는 좌표는 기존과 같이 임의 선택하지 않습니다.
- 재생성: python scripts/prepare_seoul_analysis.py. 적재 순서: 출처 → 경계 → 인구.

## 로컬 검증 결과

- 마이그레이션 0009 적용. 출처 2건+경계 1,643건+인구 36,093건을 전체 full_clean 후 단일 트랜잭션으로 저장했습니다.
- 적재·숫자 좌표·미리보기 선택·인구 출력 관련 테스트 6개 통과. Django 시스템 검사 통과.
- 실제 DB에서 남부종합시장 내부 좌표(위도 37.49477980082787, 경도 126.98491602476071)로 지역상권분석 페이지와 경계 API HTTP 200 확인. 2026Q2 원자료 수치 34,472 및 연령대·미리보기 안내 출력 확인.
- 검증 중 사용자 저장 조건 변경은 트랜잭션으로 롤백했습니다.
- 브라우저에서 외부 카카오 SDK 렌더링은 확인하지 않았습니다. Node 실행 파일이 없어 JavaScript 문법 검사도 실행하지 못했습니다.
- 전체 분석 테스트 중 기존 운영 방식 필수 입력 기대와 현재 폼 동작이 다른 2개가 실패했습니다(test_required_validation_and_optional_unknown, test_signup_reuses_required_fields). 폼의 필수 입력 설정은 이번에 변경하지 않았습니다.
- 당시 기존 StoreLocation 모델에서 is_public이 누락되어 인증 점주 지도 API에 별도 수정이 필요했습니다. 이후 공공 상가 연결 작업에서 기존 필드를 모델에 복원해 해결했습니다. public_stores_import_notes.md 참고.
