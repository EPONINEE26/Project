# 희망 업종 지도 연결 (2026-11-03)

- 실제 폼은 브랜드 세부 업종 44개와 ‘전체’를 사용합니다. 공공 업종은 247개입니다.
- 코드 대응표: `market/industry_mapping.py`의 `CATEGORY_CODES`. 24개 희망 업종을 공공 코드에 연결합니다. 프로젝트 미리보기 대응이며 공식 검증을 의미하지 않습니다.
- 나머지 업종은 명확한 대응이 없어 공공 결과를 비웁니다. 전체 업종으로 대체하지 않습니다. DB에 별도 검수된 `brand_category`/`verified=True` 대응이 있으면 함께 사용합니다.
- 제과제빵은 빵/도넛 및 떡/한과, 패스트푸드는 버거 및 토스트/샌드위치/샐러드로 한정합니다. 희망 업종과 공공 분류의 범위가 완전히 같지는 않습니다.
- 인증 점주 모드는 브랜드의 실제 category를 정확히 비교하고 공개 동의·인증 조건을 유지합니다. 검색어는 브랜드명에 적용합니다.
- 카카오 키워드 검색은 같은 세부 업종 조건을 보장하지 못하므로 희망 업종 선택 중에는 대체 검색을 중단하고 안내합니다. ‘전체’일 때 기존 대체 검색을 유지합니다.
- 업종 변경은 즉시 지도 조회에만 반영합니다. 영구 저장은 조건 저장 버튼을 사용합니다. 새 입력 UI나 탭은 추가하지 않았습니다.
- 최초 적재 및 운영 DB 변경은 실행하지 않았습니다.
- 지도 Django 테스트 7개, 시스템 검사, 마이그레이션 불일치 검사 통과. Chrome 모형 검증은 실행 환경의 GPU 초기화 오류로 완료하지 못했습니다. 실제 카카오 SDK 렌더링은 별도 확인이 필요합니다.
