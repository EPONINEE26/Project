# 탄탄 기능 확장 적용 안내 · 2026-10-30

이번 ZIP은 기존 Django 프로젝트의 전체 실행본입니다. 기존 브랜드·회원·매물 데이터는 유지했고, 신규 기능에 필요한 테이블과 필드만 추가했습니다.

## 1. Windows에서 실행

1. ZIP 전체를 새 폴더에 압축 해제합니다. 예: `C:\workspace\tantan_update\fcha_tantan_windows`.
2. `manage.py`와 같은 위치의 `start.bat`을 더블클릭합니다. 관리자 권한은 필요 없습니다.
3. Python 자동 탐색 → 가상환경 준비 → 패키지 설치 → DB 백업/변경 적용 → 관리자 계정 확인 → 브라우저 열기 순서로 진행됩니다. 첫 설치에는 인터넷이 필요합니다.
4. 검은 창의 `Server is ready` 주소를 사용합니다. 기본은 `http://127.0.0.1:8000/`이며, 사용 중이면 8001~8020 사이 빈 포트를 선택합니다.
5. 서버 창은 열어 둡니다. 종료는 `Ctrl+C`, 다시 시작은 `start.bat`입니다.

Python은 `py` 런처, `C:\python313\python.exe`, 사용자 설치 폴더, 레지스트리, PATH를 순서대로 확인합니다. 복사된 가상환경이 고장 나 있으면 별도 이름으로 보존하고 새 환경을 만듭니다. 오류 창이 즉시 닫히지 않으며 `logs\startup.log`에 원인이 기록됩니다.

**기존 PC에서 새 회원·게시물 등을 추가한 경우:** 현재 폴더를 먼저 백업하세요. 새 코드 폴더에는 현재 PC의 `db.sqlite3`, `.env`, `private_media`를 그대로 가져온 뒤 실행하세요. 첨부 DB로 최신 PC DB를 덮어쓰지 마세요. 이번 기능 확장은 실행 스크립트 3개만 복사해서 적용할 수 없습니다. 전체 새 코드가 필요합니다.

기존 관리자 계정 비밀번호는 변경하지 않습니다. 관리자 정보가 없는 최초 환경에서는 `.env`에 새 계정 정보를 준비합니다. 본 ZIP의 개인 설정은 공개 배포용 설정이 아닙니다.

## 2. 지역 살펴보기·비교

- 표 첫 열을 `비교`, 다음 열을 `브랜드`로 배치했습니다. 브랜드 앞의 글자 아이콘은 제거했습니다.
- 체크하면 비교함에 추가되고 해제하면 빠집니다. 페이지를 새로 불러오지 않습니다. 최대 10개 브랜드를 비교할 수 있습니다.
- 비교 열과 브랜드명 열은 좌측에 고정됩니다. 작은 화면에서 다른 통계를 가로로 넘겨도 체크박스를 사용할 수 있습니다.
- 시·도 → 시·군·구 → 읍·면·동을 지정할 수 있습니다. 상세 지역은 직접 입력, 등록 지역 자동완성, 주소검색으로 선택합니다. 전국 모든 행정구역을 담은 별도 오프라인 코드 목록은 포함하지 않았습니다.
- 시·도 통계는 기존 공시 데이터입니다. 세부 지역 표는 공개에 동의한 인증 점주 등록 매장만 집계합니다. 동별 공시 통계를 임의로 생성하지 않습니다.
- 지도는 인증 점주 등록 매장과 카카오 장소검색을 구분합니다. 공개 등록 매장은 최대 500개 좌표, 카카오 검색은 최대 45개 결과를 표시합니다. 검색 결과는 전체 시장의 매장 수 또는 정확한 경쟁률이 아닙니다.

## 3. 카카오 지도 연결 — 필요한 설정

지도 코드와 핀 지정 기능은 구현되어 있으나, 현재 `KAKAO_JS_KEY`가 비어 있어 실제 지도는 연결 대기 화면으로 표시됩니다. 유료 AI 키와는 별개의 지도용 키입니다.

1. [카카오 개발자 사이트](https://developers.kakao.com)에서 사용할 앱을 선택하거나 생성합니다.
2. 앱의 **플랫폼 키 → JavaScript 키**에서 사용할 키와 JavaScript SDK 도메인을 설정합니다.
3. 실제 실행 주소를 등록합니다. 기본 예: `http://127.0.0.1:8000`, `http://localhost:8000`. 자동으로 8001번으로 실행됐다면 그 포트를 포함한 주소도 등록해야 합니다.
4. 프로젝트 루트의 `.env`에 다음 항목을 채웁니다. REST API 키나 Admin 키가 아닌 JavaScript 키를 사용합니다.

```dotenv
KAKAO_JS_KEY=발급받은_JavaScript_키
```

5. 서버를 종료하고 `start.bat`으로 다시 실행합니다. 카카오 콘솔에 지도 사용 권한/활성화 절차가 표시되면 해당 앱에서 완료합니다.

공식 설정 기준: https://apis.map.kakao.com/web/guide/

양도양수 작성 화면에서 주소검색 후 지도 클릭 또는 핀 드래그로 위치를 조정할 수 있습니다. 좌표 직접 입력도 가능합니다. 정확한 위치 공개에 동의하지 않으면 매물 지도 좌표를 소수 셋째 자리로 반올림해 대략 위치만 표시합니다. 증빙서류는 지도에 공개되지 않습니다.

## 4. 점주 커뮤니티

- GNB에 추가했습니다. 자유 이야기, 매장 운영, 홍보·마케팅, 질문, 양도 경험을 검색·분류할 수 있습니다.
- 게시글과 댓글 모두 작성·조회·수정·삭제 가능합니다. 수정·삭제는 작성자만 할 수 있습니다.
- 닉네임 위에 작은 회색 브랜드명을 표시하며, 증빙에 적은 지점명은 작성자 표시에서 제외합니다.
- 작성자는 브랜드 선택 → 계약서와 사업자등록증 제출 → 관리자 승인 후 글·댓글을 작성합니다. 여러 브랜드를 인증받았다면 승인된 브랜드 중에서만 선택할 수 있습니다. 만료된 인증으로는 새 글·댓글을 작성할 수 없습니다.
- 더미 게시글 10개와 댓글 10개가 들어 있습니다. 모두 `예시` 표시가 있으며 실제 점주 의견이 아닙니다. 더미 계정은 로그인할 수 없고 점주 인증을 위조하지 않습니다.
- 초기 데이터 명령은 반복 실행해도 기존 게시물을 덮어쓰거나 더미를 중복 추가하지 않습니다.

## 5. 비속어 제거·게시물 검토

일반 텍스트 입력과 검색어는 브라우저와 서버에서 금칙어를 제거합니다. 브라우저 스크립트를 끄거나 폼을 직접 전송해도 서버 검사가 적용됩니다. 비밀번호, 인증 토큰, 이메일, 식별자, 파일 내용은 임의로 변경하지 않습니다.

관리자 `/admin/core/moderationpolicy/1/change/`에서 다음을 설정합니다.

- 자동 제거 사용 여부
- 금칙어 목록(JSON 문자열 배열, 최대 500개, 단어당 40자)
- 탐지 시 공개 글의 1차 블라인드 여부
- 2차 삭제 안내 문구(기본: `일방적 비난 혹은 근거없는 욕설로 삭제되었습니다.`)

커뮤니티 글·댓글, 점주 후기, 양도양수 매물은 관리자 목록에서 1차 블라인드 / 2차 삭제 안내 / 검토 후 공개를 선택할 수 있습니다. 블라인드된 글을 작성자가 수정해도 자동 공개되지 않습니다. 커뮤니티 신고는 관리자 검토 대상으로 접수합니다.

**판단 범위:** 로컬 금칙어 규칙은 문맥상의 비난, 사실 여부, 근거 유무를 자동 판정하지 않습니다. 일반적인 개선 의견은 허용하고 일방적 공격 여부는 신고와 관리자 검토로 결정합니다. 금칙어 조합이나 신조어는 목록을 보완해야 합니다. 2차 처리는 화면의 삭제 안내 상태이며, 관리자가 검토 기록을 보존할 수 있도록 DB 원문을 즉시 영구 삭제하지 않습니다.

## 6. 본사·점주 증빙

- 점주: 가맹계약서 + 사업자등록증
- 본사: 사업자등록증 + 본사 재직/권한 증빙(재직증명서·위임장 등)
- 파일당 10MB 이하 PDF/JPG/PNG, 기본 파일 서명과 형식 검사
- 자료 제출 후 사전점검 결과 기록, 관리자 승인/반려
- 증빙은 제출자 또는 관리자만 다운로드 가능하며 공개 정적 파일로 제공하지 않습니다.

유료 AI, OCR, 딥러닝 또는 서류 진위 판별 모델을 연결하지 않았습니다. `서류 사전점검`은 파일 형식·용량·제출 여부 확인이며, 문서 내용·명의·진위·브랜드 일치 여부는 관리자가 확인해야 합니다. 자동 승인하지 않습니다.

## 7. 고객센터·챗봇·언어

- 햄버거 메뉴의 고객센터: 통합 검색, 이용자 유형, 분류, 자주 묻는 질문 20개, 공지, 1:1 문의, 내 문의 내역
- 관리자는 고객센터 문의에 답변하고 FAQ 한글/영문 내용을 수정할 수 있습니다. 회원 문의는 본인에게만 표시합니다.
- 우측 고정 탄탄 도우미: 사이트 기능/FAQ 및 등록 브랜드 데이터를 로컬 검색하고 관련 내부 페이지를 안내합니다. 상세 브랜드 수치는 로그인 사용자에게만 제공합니다. 외부 AI 호출·결제·키 설정이 없습니다.
- 챗봇은 자유로운 추론을 하는 LLM이 아닙니다. 사이트 이용법과 등록 정보 검색 범위에서 답하며 모르는 매출이나 증빙 진위를 생성하지 않습니다.
- KO/EN 버튼: 메뉴, 주요 화면 문구, 입력 안내, 도움말을 사전 기반으로 전환하고 선택을 저장합니다. 사용자가 쓴 게시글·댓글·브랜드 고유명사를 자동 번역하는 기능은 포함하지 않았습니다. 번역을 추가하려면 `static/js/i18n.js`의 문구 사전과 관리자 FAQ 영문 필드를 수정합니다.

## 8. 회수 계산기·양도양수·모션

- 계산기 기준 브랜드는 첫 진입 시 `선택 안 함 · 직접 입력`입니다. 이름 검색으로 드롭다운을 좁히고 브랜드를 선택한 뒤 참고값을 불러옵니다. 브랜드 없이 직접 계산할 수도 있습니다.
- 양도양수는 목록/지도 구조로 구성하고 브랜드·지역·업종·보증금·월세·권리금·면적 필터, 정렬, 상세 정보, 관리비·층수·주차·입주일·시설, 작성/수정/삭제를 제공합니다.
- 버튼, 메인 배너, 카드에 짧은 진입·호버 효과를 적용했습니다. OS의 모션 감소 설정을 존중합니다.

## 9. 검증 결과와 남은 외부 확인

- Django 전체 테스트 75개 통과, 시스템 검사 통과, 누락 migration 없음
- JavaScript 파일 문법 검사 통과
- 마이그레이션 직전 DB의 기존 411,967행을 공통 필드로 대조: 값 변경 없음
- 주요 페이지의 실제 Django 렌더링 결과로 데스크톱 및 390px 레이아웃 확인
- 서버 저장·인증·권한·검열·CRUD·비교 선택은 Django 테스트 클라이언트로 확인
- 브라우저 점검은 렌더링 스냅샷을 이용했습니다. 실제 Django 서버와 브라우저를 연결한 전체 상호작용 테스트는 이 실행 환경에서 수행하지 않았습니다.
- Windows PC의 BAT/PowerShell 실행과 실제 카카오 지도 연결은 사용자 PC 및 JavaScript 키 설정 후 확인이 필요합니다.

문제가 있으면 `logs\startup.log`와 어떤 화면·동작에서 발생했는지 알려주세요. 오류 확인을 위해 PC 전체 관리자 권한을 줄 필요는 없습니다.
