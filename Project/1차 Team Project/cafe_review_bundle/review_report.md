처리일: 2026-10-28. 자료: records.zip 내부 records.csv와 brands_by_category.zip 내부 카페.json. 다른 업종 JSON의 브랜드는 추가하지 않았습니다.

## 결과와 해석

이 결과는 **상호명 기반의 보수적 지도 채택본**입니다. 실제 가맹계약, 현재 영업, 과거와 현재의 운영 주체를 전수 확인한 확정 명부가 아닙니다. 불확실한 행은 삭제하지 않고 별도 검토 파일로 남겼습니다. 검색은 아래 근거 항목과 해당 행에 한해 수행했으며, 보류 전체를 개별 검색한 것은 아닙니다.

원본 840,254 = 지도 23,691 + 보류 45,399 + 후보 미검출 771,164. 브랜드 842개를 순서·id·name 그대로 유지했습니다. 매장 행이 있는 브랜드는 433개, 나머지 409개는 모든 지역이 빈 배열입니다. 이름이 null인 coffee_20240319도 그대로 유지하고 매장을 배정하지 않았습니다.

**후보 미검출은 해당 브랜드가 아니라고 확인한 수가 아닙니다.** 탐색 사전에 없는 오탈자·약칭·법인명만 기재된 매장은 놓칠 수 있습니다. 광범위 탐색 보류에는 이름 일부가 우연히 같은 무관 업소가 많이 포함되어 있습니다. 보류 수를 실제 프랜차이즈 매장 수로 읽으면 안 됩니다.

## 데이터 구조와 원본 보존

cafe_map.json의 최상위는 배열이며 각 객체는 id, name, regions만 갖습니다. regions는 기준 17개 지역과 원본 특수값 1개를 합친 18개 키를 모든 브랜드에 동일하게 둡니다. 매장에는 rdnmAdr, bldNm, lat, lon, bizesId, bizesNm, brchNm, ctprvnNm, signguNm, dongNo, flrNo, hoNo, marker_title을 넣었습니다. lat/lon은 유한한 JSON 숫자, 나머지는 원본 문자열입니다. 원본 공란은 빈 문자열이며 추정으로 채우지 않았습니다.

marker_title은 원본 bizesNm을 쓰고, 정규화 비교에서 지점명이 이미 포함되어 있지 않을 때만 원본 brchNm을 공백으로 이어 붙였습니다. 원본 주소·층·호·좌표는 검색 자료로 덮어쓰지 않았습니다. 매출·매장 수 history 통계는 매장 좌표로 사용하거나 결과에 복사하지 않았습니다.

## 매칭 규칙

공백·기호·HTML 엔티티·영문 대소문자·악센트를 정규화하고 한영 병기 괄호 안팎을 별칭으로 추출했습니다. 전체 상호 일치, 기준 이름 뒤의 지점 표기, 원본 주소/행정동/건물/지점명에 있는 지역 단서가 뒷부분을 설명하는 경우를 연결 후보로 보았습니다. 이름이 중간에 들어있다는 이유만으로 지도에 넣지 않았습니다. 가장 구체적인 이름이 일치할 때 하위 브랜드를 우선하되, 동일 별칭이 복수 ID에 해당하면 자동 선택하지 않았습니다.

짧거나 일반적인 이름, 명시적 과거명, 복합상호, 기준에 없는 하위 브랜드 표기, 시설·공장 가능성, 비카페 업종은 추가 검토 사유입니다. 단어가 일반적인지에 대한 명시적 보수 목록과 짧은 이름 허용 목록은 build.py에 공개했습니다. 이 목록은 의미 판정을 완전 자동화하거나 정확도를 통계적으로 입증한 것이 아닙니다. 별칭 원천/허용 상태는 alias_registry.csv, 행별 적용 근거는 match_audit.csv에 있습니다. 약칭 후보를 모두 허용하지 않았습니다.

history에 들어있는 카페베네 등을 현재 바리스텔라로 일괄 연결하지 않았습니다. 더커피(The coffee)와 더커피(the coffee)는 ID가 다르며 대소문자로 구분하지 않았습니다. 오슬로우의 두 ID 역시 지역으로 임의 배분하지 않았습니다. name=null인 브랜드의 과거 이름만으로 매장을 할당하지 않았습니다.

## 중복과 동일 주소

전체 CSV의 bizesId는 모두 서로 달랐습니다(동일 ID 복수행 0). 완전 동일 원본행도 없으므로 제거한 행은 0이며 duplicate_removals.csv는 헤더만 있습니다. 주소·건물명·좌표가 같다는 이유로 합친 행도 0입니다.

단일 브랜드 연결 후보들에서 같은 브랜드·원본 지역·정규화 도로명주소의 복수행을 642묶음 탐지했습니다. 이 중 묶음 전체의 주소·건물명·좌표 네 원본 문자열이 모두 같은 것은 427묶음입니다. 641묶음은 동일 매장/다층 사용/별도 매장 구분을 확정할 수 없어 보류했습니다. 한 묶음의 경희대 컴포즈 3행은 공식 검색 색인의 서로 다른 지점명과 CSV 지점 표기를 근거로 각각 보존했습니다. 이것도 현재 동시영업 확인은 아닙니다.

duplicate_review.json은 모든 탐지 묶음에 원본 39개 열과 CSV 행 번호, 상태, 이유, 검색 여부를 남깁니다. 주소가 같은 다른 건물·대학교 내부 매장과 여러 층을 쓰는 한 매장을 자동 판정하지 않았습니다. 층이나 호가 다르다는 사실만으로 별도 매장으로 확정하지 않았습니다. 현재 탐지는 단일 브랜드 연결 후보의 같은 주소를 기준으로 하므로, 이름이 불명확한 보류·주소가 다르게 기재된 동일 매장·도로명주소가 다른 인접 건물까지 모두 찾아낸 결과는 아닙니다.

이전 제거 289행과 추가 병합 174행은 개별 행 목록이 첨부되지 않아 이번 원본 행과 1:1 대응시킬 수 없습니다. 이전 결과를 재사용하지 않고 CSV 전체를 다시 읽었으며, 이전 숫자에 맞추는 제거·복원은 하지 않았습니다. 이전의 147/12/11묶음 판단을 아는 것으로 가정하지 않았습니다.

## 좌표와 주소

CSV 840,254행 전체에서 lat/lon 누락·비숫자·비유한 값 0행, 위도 -90~90/경도 -180~180 범위 오류 0행, 한국 주변 점검 사각형(북위32~39.5, 동경124~132) 밖 0행입니다. 이 사각형 검사는 행정경계나 영업장 실제 위치 검증이 아닙니다. 지도 채택 행의 좌표를 숫자로 변환한 뒤 원본 숫자값과 다시 비교했습니다.

**실제 주소와 좌표가 일치하는지 역지오코딩 또는 지도 전수 대조는 하지 않았습니다.** 건물 대표좌표를 공유하거나 층·호가 잘못된 행일 수 있습니다. 공개 장소의 층이 CSV와 다른 사례는 보고서 근거에 남기고 원본을 바꾸지 않았습니다.
