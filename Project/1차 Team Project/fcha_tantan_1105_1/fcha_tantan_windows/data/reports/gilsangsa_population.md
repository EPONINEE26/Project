# 길상사 인구 연결

2026-11-04에 상권 코드 3110281에 최신 분기 2026Q2 자료를 추가했습니다.

| 종류 | 총계 | 남성 | 여성 |
|---|---:|---:|---:|
| 직장인구 | 1428 | 1088 | 340 |
| 유동인구 | 67344 | 31288 | 36057 |

직장인구는 명, 유동인구는 기존 정책에 따라 원자료 수치로 표시합니다. 유동인구의 성별 합계가 총계보다 1 크지만 원본을 수정하지 않았습니다. 두 종류 모두 연령별 자료를 저장했고, 유동인구는 요일별·시간대별 자료도 저장했습니다.

`PopulationStat.by_gender`와 마이그레이션 0012를 추가했습니다. 지역상권 화면의 인구 상세에 성별 자료, 유동인구 상세에 성별·연령별·요일별·시간대별 자료를 표시합니다. 다른 상권의 미등록 성별 자료는 빈 값으로 유지합니다.

DB와 `01_sources.json`, `04_population.json`을 동기화했습니다. DB는 마이그레이션 전에 `data/backups/before_gilsangsa_population_*.sqlite3`, JSON은 `data/backups/area_population_json_*/`에 백업했습니다.

재적재(기본 검증, 저장하려면 `--commit` 추가):

```powershell
python manage.py import_area_population 3110281 --worker '../fdata/서울시 상권분석서비스(직장인구-상권).csv' --floating '../fdata/서울시 상권분석서비스(길단위인구-상권).csv'
```

검증: 인구 적재 테스트 3개 통과(검증 전용, 중복 방지, 성별 합계 차이 보존, JSON 출력 포함). 유동인구 상세 템플릿의 성별 수치 렌더링과 Django 시스템 검사 통과.
