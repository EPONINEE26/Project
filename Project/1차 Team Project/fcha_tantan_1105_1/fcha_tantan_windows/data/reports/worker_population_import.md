# 직장인구 CSV 적재

2026-11-04, `서울시 상권분석서비스(직장인구-상권).csv`의 최신 분기(2026Q2)를 적재했습니다.

- `PopulationStat(kind='worker')`: 총 직장인구, 6개 연령대 인구, 단위(명), 기준 분기, 출처 저장.
- 기존 공식 상권 코드에 연결한 1,634건 저장. 동일 상권·분기·종류는 갱신하며 다른 인구 종류와 과거 분기는 보존합니다.
- 경계 DB에 없는 7개 코드 제외: 3110542, 3110515, 3110407, 3110281, 3110270, 3110234, 3110137.
- 명칭 차이 3개는 코드로 연결: 3001494, 3110379, 3110024. 경계의 명칭은 보존합니다.
- 원본 성별 상세 수치는 CSV에 보존합니다. CSV에 없는 가구·요일·시간대 수치는 생성하지 않습니다.
- SQLite DB는 저장 전 `data/backups/before_worker_population_*.sqlite3`로 백업합니다.

```powershell
python manage.py import_worker_population '../fdata/서울시 상권분석서비스(직장인구-상권).csv'
python manage.py import_worker_population '../fdata/서울시 상권분석서비스(직장인구-상권).csv' --commit
```

지역상권 화면(`/brands/bregion/`, `brands/templates/bregion.html`)에서 분석 위치가 공식 상권에 연결되면 직장인구 총계, 주요 연령 비중, 상세 연령별 인구, 기준 분기와 출처가 표시됩니다. 분석 위치가 상권에 연결되지 않으면 자료 미연결로 표시합니다.

검증: 신규 적재 테스트 2개 통과 및 Django 시스템 검사 통과. 함께 실행한 기존 분석 테스트에서는 운영 방식 필수 입력 관련 테스트 2개가 실패했습니다(이번 변경에서 해당 폼은 수정하지 않음).
